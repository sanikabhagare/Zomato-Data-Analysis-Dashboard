Designed and created an interactive Excel dashboard analyzing 10,000+ Zomato restaurant records. Utilized Pivot Tables, Slicers, conditional formatting, and Excel functions to evaluate pricing distribution, rating trends, and online delivery performance across 5 major cities.

# 📊 Zomato Restaurant Data Analysis & Interactive Excel Dashboard

## 📌 Project Overview
An end-to-end data analysis project exploring 10,008 restaurant records from Zomato using **Microsoft Excel**. The goal is to analyze restaurant ratings, pricing trends, online delivery availability, and customer feedback across 5 major cities to derive key business insights.

## 🛠️ Excel Features & Techniques Used
- **Data Cleaning & Formatting:** Cleaned raw data, handled missing values, and created conditional formatting for quick visual insights.
- **Pivot Tables & Pivot Charts:** Aggregated 10,000+ rows to calculate city-level averages, cuisine distributions, and delivery metrics.
- **Excel Formulas:** Used `AVERAGE`, `COUNTIF`, `SUMIFS`, `VLOOKUP`/`XLOOKUP`, and `INDEX/MATCH` to calculate KPIs.
- **Interactive Dashboard:** Built a dynamic dashboard layout using Slicers, Pivot Charts, and KPI summary cards.

## 💡 Key Business Insights
- **Total Restaurants Analyzed:** 10,008
- **Cities Covered:** 5 major cities (Highest restaurant count in Pune)
- **Average Rating:** 3.50 / 5.0
- **Average Cost for Two:** ₹1,593
- **Online Delivery:** ~49.1% of listed restaurants offer online delivery.
